## 商品説明文（本の紹介文）

KDPの「本の説明」欄（HTML可、上限4000文字）にそのまま貼れる分量で用意しました。太字にしたい箇所は`<b>`タグの案も添えています。

```html
シャッターを押した瞬間、その場で紙にプリントされる——そんな体験を、3台の小さなマイコンボードで作ってみませんか。

本書は、M5Stack社の<b>ATOM Printer Kit（感熱プリンター内蔵）</b>、AIカメラ<b>M5StickV</b>、電子ペーパー端末<b>M5Paper</b>を組み合わせ、「AIカメラで撮った写真が、その場で顔検出されてラベル付けされ、iPhoneや電子ペーパーで確認したうえで感熱紙に印刷される」という、実際に動くIoTシステムをゼロから作り上げる電子工作入門書です。

架空の説明ではありません。本書が題材にしているのは、実在するオープンソースのファームウェア・回路・通信プロトコルです。配線図もソースコードも、すべて実機での検証や公式ドキュメントに基づいて解説しています。

<b>本書で学べること</b>
・IoT（モノのインターネット）の基礎知識をゼロから
・UART／Wi-Fi／HTTPという3種類の通信方式の違いと使い分け
・PlatformIO・Arduino IDE・MaixPy IDEという3つの開発環境の構築方法
・M5Stackシリーズ（Core系・ATOM系・Stick系・Paper系など）全体のラインナップ整理
・ATOM Lite＋感熱プリンターの配線と書き込み、Wi-Fi初期設定
・M5StickV（Kendryte K210搭載AIカメラ）による撮影・顔検出・UART直結転送の仕組み
・電子ペーパー端末M5Paperを使った、物理ボタンだけの操作系構築
・画像を白黒に変換する誤差拡散（Floyd–Steinberg）ディザリングの原理
・curl・PythonからHTTP APIを直接叩くプログラム連携
・実機トラブルシューティングと、よくあるつまずきポイントの回避法

<b>こんな方におすすめです</b>
・Arduino・M5Stack系のボードは触ったことがあるが、複数デバイスを連携させた経験がまだない方
・IoTという言葉は知っているが、実際に手を動かして仕組みを理解したい方
・電子工作は初めてではないが、通信の仕組み（Wi-Fi・UART・HTTP）を整理して学びたい方

電子工作もプログラミングも「はじめて」という方でも読み進められるよう、第1章では前提知識をゼロから解説しています。本書を読み終える頃には、あなたの手元にも、撮って・見て・印刷できるIoTカメラ&プリンターが（あるいはあなた自身のアイデアを加えた発展版が）動いているはずです。
```

※ Amazonの説明文エディタでHTMLタグが反映されない場合は、`<b>`と`</b>`を取り除いたプレーンテキスト版を使ってください。

KDPのカテゴリーは固定の分類ツリーから選ぶ形式のため、実際の登録画面で近い名称を検索して選択してください。本書の内容（電子工作・IoT・プログラミング実践）に合う候補は以下の通りです。
